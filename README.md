# diep-rework

diep.io 經典 2D 射擊遊戲的純前端重製專案。基於 TypeScript、Pixi.js v8 與 Vite 開發，採用模組化 ECS-lite 架構，重現原版的坦克物理、子彈相消彈道、經典轉職樹與 AI 生態。

---

## 專案特點

- **純前端運作**：無需後端常駐服務，所有遊戲循環、物理模擬、AI 決策與 UI 均在瀏覽器內執行。
- **25 TPS 固定步長模擬與插值渲染**：底層邏輯嚴格以每秒 25 tick 運行，渲染層透過座標與角度插值（`lerpAngle`）支援 120+ FPS 高更新率螢幕，兼顧精確判定與流暢視覺。
- **自研 2D 物理與碰撞檢測**：
  - 圓形剛體推開與動量反衝。
  - 高速子彈掃掠防穿透（Swept CCD）。
  - 子彈互相抵消物理（Bullet Clash）。
  - 基於 `TypedArray` 的零配置空間雜湊（SpatialHash），高效處理高密度交火。
- **零 GC 熱路徑設計**：核心循環全面採用物件池（子彈、粒子）與預烘培共用貼圖 Sprite 池，避免記憶體回收造成的畫面卡頓。
- **原汁原味數值體系**：
  - 8 項屬性加點機制（生命恢復、最大生命、撞擊傷害、子彈速度、子彈貫穿力、子彈傷害、裝填速度、移動速度）。
  - Tier 1（Lv 1）、Tier 2（Lv 15）與 Tier 3（Lv 30）坦克轉職樹。
  - 各職業專屬視野縮放（FOV）、砲管後座力與彈道散佈。
- **自主 AI 決策系統**：具備切線避障、威脅偏轉、戰鬥實力差距評估與預判引導射擊的有限狀態機。
- **All-in-Canvas UI**：全 UI 整合於 Pixi.js 渲染管線，包含升級面板、轉職卡牌、即時排行榜、小地圖與死亡結算。
- **內建除錯沙盒（DebugOverlay）**：按下反引號鍵（`` ` ``）可開啟開發者面板，支援無敵模式、一鍵升級/轉職、生成 AI、自由視角（Freecam）與壓力測試。

## 遊戲操作

| 按鍵 / 操作 | 功能說明 |
| :--- | :--- |
| `W` `A` `S` `D` | 坦克八向移動 |
| `滑鼠移動` | 瞄準方向 |
| `滑鼠左鍵` / `Space` | 開火 |
| `E` | 切換自動開火（Auto-Fire） |
| `C` | 切換自動旋轉砲管（Auto-Spin） |
| `1` ~ `8` | 快速升級對應屬性點數 |
| `` ` ``（反引號） | 開啟 / 關閉除錯監控面板（DebugOverlay） |
| `Enter` | 死亡後快速重生 |

## 本地開發與建置

### 環境需求
- [Node.js](https://nodejs.org/)（建議 18.0 以上版本）
- npm、pnpm 或 yarn

### 安裝與啟動

1. **安裝依賴套件**：
   ```bash
   npm install
   ```

2. **啟動本機開發伺服器**：
   ```bash
   npm run dev
   ```
   啟動後至瀏覽器開啟 `http://localhost:3000` 即可開始遊戲。

3. **執行單元測試**：
   ```bash
   npm run test
   ```
   使用 Vitest 執行物理、數值、轉職與 AI 的全套單元測試。

4. **型別檢查與程式碼風格掃描**：
   ```bash
   npm run typecheck
   npm run lint
   ```

5. **建置生產環境檔案**：
   ```bash
   npm run build
   ```
   打包產物將輸出至 `dist/` 目錄。

## 核心目錄架構

```text
src/
├── ai/          # AI 決策狀態機、引導射擊與行為設定
├── config/      # 遊戲常數、等級經驗表、屬性換算與坦克職業配置
├── core/        # 主遊戲中樞、遊戲循環、固定步長器、相機與輸入管理器
├── debug/       # 開發者除錯面板（DebugOverlay）與觀戰模式
├── entities/    # 坦克、子彈、形狀與粒子之純資料模型
├── physics/     # 自研 2D 物理世界與空間雜湊網格（SpatialHash）
├── rendering/   # Pixi.js 場景容器、貼圖池與各實體渲染器
├── systems/     # 戰鬥碰撞、開火、升級、回血與生成邏輯系統
└── ui/          # Canvas HUD、屬性加點面板、轉職卡牌與排行榜
```
